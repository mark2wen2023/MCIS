从 `309b0cc` 只改分析页图表适配与本目录验收。原样复用 `2048c60` 的 `tests_acceptance/shared-trajectory-cross-repo` 与 `...-expanded` 两份合成单船 JSON（见 SHA256SUMS），不改原件、契约、正式接口、算法、主线、CI、3D 或 4A。

## 断段规则

对每条折线，看相邻两点形成的**完整线段**是否与已声明的**开区间**重叠（`lo < end && hi > start`）。重叠则在实际 ECharts `option.series[].data` 中写入裸 `null` 断点，并设 `connectNulls: false`。不是探测中点，也不是等待展示格点落入缺口。

- 关键反例 `(6,7)`：整个落在展示格 5、10 之间；`[5,10]` 的中点 7.5 不在区间内。
- expanded 对照 `(121, 127.5)`，同时保留原件中的 `(60,100)` 声明。
- 非居中反例 `(1,2)`，位于 0/10 展示间隔内；中点 5 不在区间内。本条为装配手造，不是 2048c60 原件。

6、7（以及 1、2；121、127.5 若该船有原始点）保留为端点，内部不虚报。距离 / DCPA / TCPA 按两船声明缺口的并集断段，不连线、不造零。船速只断缺轨的那条船，对照船不改写。

缺口元数据仅由本隔离装配的 `cases.json` 显式传入。现场 `GET /cases/{id}/analysis` 使用不含 `declaredOpenGaps` 的合成入口种子，不得猜测缺口。

距离在同刻原始点上为几何（haversine）值；DCPA/TCPA 为装配声明占位，**不是**本轮官方 mcis-core 复算。
