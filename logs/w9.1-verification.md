## Product boundary

Investigators with case write permission can add a vessel, record per-field declared sources, save and reopen it. Duplicate IDs never overwrite existing vessels. Unknown-result recovery is read-only before a manual retry. Existing vessels remain compatible.

This is not full W9: editing/deleting, environment input, extended maneuvering parameters, automatic source verification, AI extraction, simulation/analysis recomputation and production authentication are not delivered by this slice. No deployment occurred.
