# W13.1 local replay adapter

Implemented and frozen for independent acceptance; not an integrated Unity replay release.

- New Presentation/ReplaySync immutable DTO, command adapter and read-only state snapshot. No existing clock, HUD, HTTP, authentication, service, seed or historical provenance files changed.
- Caller supplies already-authorized/deserialized commands and a clock configured for this case; only one thread may call the adapter. JSON field mapping, main-thread dispatch, HTTP polling, ≤10Hz state publication and persistent restart recovery are not implemented. Fixture JSON mapping is tested only, not a production client.
- Case validation precedes deduplication. Cursor starts at explicit confirmedSeq (default0). Only contiguous commands advance it. Sorted batches prevalidate all parameters and conflicting same-seq payloads. Duplicate identical commands collapse in a batch; Applied/Duplicate/Rejected/FailedUnknown are local result types, not new wire fields.
- Already-confirmed history without an in-memory payload is rejected as unverifiable. Successful command deduplication exists only in this adapter lifetime. Rejections stop a batch; earlier successes are not rolled back.
- Seek outside configured range is rejected before any clock effect. Same-time seek follows real SimClock: driven systems evaluate but TimeChanged may not fire. Rate is exactly one of .25,.5,1,2,4,8,16,32.
- Focus emits injected intent only. Exceptions from clock events/focus can follow a real side effect: adapter latches OutcomeUnknown, retains previous confirmed cursor and blocks later execution. No exactly-once or safe retry guarantee in this state. Upstream must reconcile actual state before reconstructing an adapter.
- Self-tests: 35 passed,0 failed,0 skipped (logs/w13.1-selftest.txt). Uses real SimClock and driven-system observation. One initial test-data binding typo (int to nullable double) was fixed, not an implementation failure.
- netstandard2.1/C#9 build:0 warnings,0 errors (logs/w13.1-libcheck.txt). git diff --check passed. Six new files in frozen manifest.
- No Unity scene, browser rendering, HTTP roundtrip, network synchronization or real camera movement was tested. Stage/push not performed.
