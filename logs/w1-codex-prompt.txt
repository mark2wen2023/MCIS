【功能需求】
实现按时间判定会遇局面、两船让路/直航责任、应采取行动 vs 实际操纵，并输出时间带 + 逐条核查结果。

1) 会遇局面（在「存在碰撞危险」时判定；危险判据可配置，默认可用 DCPA 低于阈值且 TCPA>0，或距离正在接近）：
   - R13 追越：他船从本船正横后大于 22.5° 的方向赶上，即他船相对本船船首向的相对方位落在 [112.5°, 247.5°] 扇区（边界角 112.5° 必须可配，默认 112.5）。追上的船为让路船，被追越船为直航船。一旦成立，在驶过让清前保持追越局面（R13 存疑视为追越）。
   - R14 对遇：互见的机动船航向相反或接近相反以致有碰撞危险。默认「接近相反」= 航向差与 180° 之差的绝对值 ≤ 6°（对遇半角 6° 可配），且他船大致在前方。双方均应向右转向，无单方直航。
   - R15 交叉：互见且非追越、非对遇。他船在本船右舷者为让路船，另一艘为直航船；让路船应避免横越他船前方。
   - R19 能见度不良/未互见：能见度 < 可配置阈值（默认建议 2.0 nm，可配）或请求显式标明未互见时适用。此时不适用 R13–R18 的让路/直航划分（双方都有行动义务）。应核查：以安全航速行驶；对正横以前的他船避免向左转向（被追越除外）；对正横或正横以后的他船避免朝其转向。
   判定优先级：未互见/能见度不良 → R19；否则追越优先于对遇/交叉；再对遇；再交叉。
   架构验收还提到狭水道：请求里用布尔 InNarrowChannel（本阶段没有航道几何）。当标志为真时，规则清单应出现 R9；若无航道几何，R9 几何项（尽量靠航道右侧外缘行驶）可为 NotApplicable 并注明缺少航道几何，但时间带/清单必须覆盖狭水道场景。不要因为缺少 ENC 而静默忽略 R9。

2) 应采取 vs 实际行动（R8 / R16 / R17，并与局面规则结合）：
   - 实际操纵从航向、航速随时间的变化检测：右转/左转、加速/减速、保向保速。阈值可配（例如「大幅度」转向默认 10°，「保向」容差、「保速」容差、提早行动的剩余 TCPA 或距离门限）。
   - R8：行动应及早、明显（大幅度）、能导致在安全距离驶过。
   - R16：让路船应及早地大幅度行动以便他船明确让清。
   - R17：直航船应保向保速；当看出让路船显然未采取适当行动时可采取行动；若单凭让路船已无法避碰则应采取最有助于避碰的行动；交叉局面下采取行动的机动船，在环境允许时不应朝本船左舷的来船向左转向。本规则不解除让路船义务。
   - R14：双方应向右转向；向左转应判为不满足。
   每个「应采取」条目对应同一时段的「实际」操纵，并给出符合/不符合/不适用（如 UI 也可有「部分符合」）+ 依据数值（相对方位、航向差、DCPA、TCPA、航向变化、航速变化、能见度等）。

3) 输出：
   - 按时间合并的会遇局面时间带（局面 + 适用规则 + 两船角色在带内保持不变则合并）。
   - 逐条规则核查表（至少覆盖 R8、R13、R14、R15、R16、R17、R19，以及有狭水标志时的 R9）。
   - 每条核查：Satisfied / NotSatisfied / NotApplicable（可用 Partial），针对各船或双方，并附依据数值。
   - 整份报告必须固定带免责声明原文：「仅作安全调查技术分析，不作责任认定。」不得输出责任认定表述。

4) 所有阈值可配置，并有 Default。至少包括：对遇半角（6°）、追越正横后角（22.5°，即相对方位边界 112.5°）、能见度不良阈值、碰撞危险 DCPA、安全驶过 DCPA、大幅度转向角、大幅度变速、保向/保速容差、采样间隔、提早行动时限。阈值必须进入报告（便于审计）。

【必须覆盖的测试（合成航迹，不要用真实报告）】
- 正对遇（航向差 180°）→ HeadOn，双方义务为向右转向。
- 对遇边界：±6° 仍为对遇；略大于 6°（例如 6.1° 或 7°）不再判对遇（在有碰撞危险时应变为交叉）。
- 追越边界：相对方位刚好进入 >112.5°（或默认闭开区间需在测试中写清并与实现一致，推荐：大于 112.5° 且小于 247.5° 为追越扇区；正好 112.5° 的归属要在测试里固定一种并实现与之一致）判追越；略小于 112.5° 在互见且非对遇时判交叉。
- 交叉：他船在右舷 → 本船让路；他船在左舷 → 本船直航。
- 能见度不良/未互见 → R19，不套用 R14/R15 让路直航。
- R19：对正横以前来船向左转向 → 该条不满足。
- 对遇中一船向左转向 → 该船 R14 不满足。
- 让路船及早大幅度右转 → R16/R8 满足；直航船保向保速 → R17 满足。
- 时间带：能见度由不良转为互见（或局面由追越转为驶过让清）时，应出现分段而非单一局面贯穿全程。
- 阈值可配：把对遇半角从 6° 改为 10° 后，8° 航向偏差应从交叉变为对遇。
- 报告含免责声明全文。
- 狭水道标志为真时，清单含 R9。
每种会遇局面至少一例，边界角必须测到。
