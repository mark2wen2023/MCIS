## Contract and behavior reviewed

The local adapter enforces case identity before deduplication, exact supported rate values, finite and in-range seeks, contiguous successful sequence advancement and immutable payload comparison. Sorted batch prevalidation rejects invalid/conflicting payloads before applying earlier entries; a sequence gap stops execution after any already-completed contiguous prefix (not an atomic transaction).

Independent fixtures exercise case mismatch vs duplicate; sorting/exact duplicate coalescing; gaps and resumption; same-sequence conflicts; invalid batch no side effects; out-of-range/nonfinite seek; unsupported/nonfinite rates; real clock seek accuracy <0.1s; play,4x tick and pause; snapshot immutability; explicit restart checkpoint and unverifiable history; reentrant callback rejection; focus intent exception; and a real Clock.TimeChanged subscriber throwing after time has already changed. That last test verifies no cursor advancement, OutcomeUnknown lock and no retry side effect. Focus success means callback invocation only, not camera movement.

Constructor confirmedSeq is an explicit externally established checkpoint, not durable exactly-once processing. No persisted payload ledger, network polling, server acknowledgment, authentication, Unity main-thread dispatcher or camera/scene implementation is supplied. A fresh adapter without checkpoint rejects a later sequence as a gap; checkpoint history cannot be asserted duplicate when payload was not retained. Failure locks this instance; reconstructing it is an upper-layer reconciliation decision, not an automatic retry path. CaptureState is a read-only local snapshot; service supplies timestamps when a separate publisher sends it.
