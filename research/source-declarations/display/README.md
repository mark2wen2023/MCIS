固定比较器基线：2e9593657cf1ab1dafbf7ee815d9ef0a06f9bd8d；compare.mjs 未修改。输入仅为 scenarios.mjs 的手造内存对象。view.mjs 生成转义的 HTML 字符串，page.mjs 的实际 change 回调全量替换展示；index.html 是独立入口源码，不注册正式路由。本轮没有启动服务器或打开浏览器，浏览器模块加载方式/兼容性未验，不提供启动许可。不读取案例、种子、媒体或应用，不调用 API，不上传或写入业务关联，无缓存、定时器、重试或持久化。

## 配对和跳过规则

固定角色表只映射笔录 record.evidenceId/sourceSha256 到比较器相同的运行字段：audio=currentSha256；pdf/image=各自 candidate.source 与 sourceVersions 双摘要；image_raw_output=raw 双摘要；image_candidate=独立 candidate 摘要。无数组位置/名称/摘要自动匹配。

字段 present 只显示“字段合法（不代表一致）”。行结论仅在两字段均 present 且 pair 没有除 id_mismatch/digest_mismatch/source_inconsistent 之外的问题时计算：ID 精确比较，合法摘要仅折叠十六进制大小写。其他问题一律保守阻断全部来源行（可能比比较器更保守）。跨案/角色不明跳过的字段不补读；不可用载荷不读取。无映射则明确不可比较。双摘要内部不一致保留原 issue，单行相等不能掩盖总体不可确定。

聚合问题完整显示，单项状态与行结果分离；同案不同笔录即便每行一致也显示整体不可确定，明确单行一致不代表整体一致。字段有效性及原值逐项显示，missing/null/empty/invalid 分开，摘要换行不截断。所有原值以文本转义；颜色不是唯一提示。显著提示未核验原件、未证明人工批准、未建立关联。历史事件仅由调用者提供，不代表服务端历史。
