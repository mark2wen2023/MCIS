# Isolated Pi semantic blind research protocol

No production tool, Skill/profile or fact writes. Fixed 11-case corpus SHA256 77cdbdf3f2656aa57b0772fadc909671bf5bbfbd7c480a3fcbb1cc79460ad19b. Before reading credentials, Python checks corpus bytes and creates a projection of only id/sourceText/sourceSha256/sourceLocator/claim/citation. Model IDs are opaque case_001..case_011, never original semantic case names. Suggested labels, corpus rationale, expert reviews and fixture predictions are excluded. The host retains original ID mapping for final offline comparison only.

Frozen manifest pins system prompt, tool schemas, input fields, opaque ID policy, endpoint/model, 4 model/8 tool/180-second budgets, marker and meaning. Input digest binds exact projected data. Python is the trusted history and call-ID owner, not arbitrary caller/model context. read_blind_cases has no args. validate_predictions takes content JSON with exactly predictions [{itemId,label,rationale}], covering all 11 opaque IDs exactly once. Feedback is schema/coverage only, never semantic correctness. Each validation clears prior candidate first. Completion requires source read, latest valid candidate and exact terminal MCIS_BLIND_VALIDATED; host returns its stored candidate mapped to original IDs. No retry, no alternative URLs/tools/files.

Python parent holds a startup JSON apiKey in memory only. Real mode rejects TTY input to prevent terminal echo; use authorized non-echo pipe. No key in environment, argv, output, files or Node child. Node child uses official Pi 1.5.2 Agent with only the research tools. --fixture substitutes transport explicitly, has no key or network, and returns scripted_fixture origin; --approved-blind is separate and has no fallback.

Before transport dispatch, model_request returns request_attempt_started event. Node must exclusively create mode0600 receipt and fsync attempt before request_attempt_ack. Python does not dispatch before ack. Receipt is operational evidence, not signed audit; incomplete/request-inflight runs are unknown and never retried automatically. Completed valid results require Node close/completion and successful process exit. On abrupt kill a receipt without completion remains unknown even if provider finished. Caller-provided receipt path is never exposed to model.

Python external stdout is safe final predictions/metadata or generic failure, not raw provider messages, reasoning or exceptions. Internal pipe carries bounded protocol only. Max96 commands,1MiB line,8MiB aggregate; absolute180s also covers buffered commands and response return. Separate final offline evaluate may compare provisional suggested labels, never accuracy, certified experts or activated facts.
