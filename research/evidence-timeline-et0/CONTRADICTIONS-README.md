`contradictions.py` adds a local, pure read-only check of *direct* strict-before relations against explicitly selected confirmed, same-basis scoped corrections. It returns candidate source/version references and selected calibration revisions only when uncertainty-expanded intervals make the direct order impossible. Equality cannot satisfy strict before. It does not alter original event, timestamp, range, relative wording, source or calibration. A human must review any candidate; the result does not establish identity, error, fault or legal conclusion. Overlap, relative-only, missing/proposed calibration and mismatched target bases yield no candidate, not proof of consistency. Direct relations only, no transitive contradiction detection. Existing relative cycle validation rejects rather than adjudicates cycles.
