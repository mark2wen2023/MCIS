## Actual checks
The PDF has two physical pages with MediaBox [0,0,600,800], no page rotation. Page 1 says 08:30 is a rehearsal schedule, not an observed alarm. Page 2 says 08:30 is a panel alarm display with unverified calibration; its table and text are rotated 90 degrees by the PDF content transform. It is not a page /Rotate operation.

PyMuPDF actually opens the generated bytes, extracts one 08:30 word per physical page, verifies the text crop, and checks directions (1,0) and (0,-1). It renders both pages at 2 pixels per PDF point, 1200 by 1600 pixels. Raster candidate boxes are deliberately derived from the text-layer rectangles; there is no image detection or OCR claim.

The test host binds SHA, physical page and verified original text-layer bbox. Raster top-left coordinates map to PDF bottom-left coordinates as [x0/2,800-y1/2,x1/2,800-y0/2]. Results are compared against the PDF library's inverse page transformation matrix. Float32 geometry causes about 0.000015-point rounding; the explicit tolerance is 0.0001 PDF point, not a semantic tolerance. The initial tighter 0.00001-point trial failed and was corrected before the recorded passing run. This validates coordinate consistency using the same library geometry, not an independent parser accuracy study.

Wrong SHA or wrong page rejects even though both pages contain the same time. Missing transform, altered scale/rotation/dimensions, or a box from the other page cannot report exact geometry: page-only with pdfBox=null. Inputs remain unchanged. Mapping success is named text_layer_bbox, a font-metric bounding rectangle, not an exact ink outline or OCR confidence score.

## Limits
Only this generated unencrypted two-page PDF, zero crop origin, no page /Rotate, 2x rendering and actual content-rotated text are covered. Other crop/media boxes, deskew, resampling, arbitrary page rotation and OCR require separately verified transformations. The host is a local synthetic test context, not authenticated authority or human approval. Repeated time strings do not establish event identity, clock alignment, causality or semantic support. No model evaluation or production document access was exercised.
