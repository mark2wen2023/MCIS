## 可说明而有限的排名

仅用现有卡片 `content.kind == Case`、`status == Published` 与 `content.tags`，返回最多5个正分结果。标签按生产既有strip/casefold形式归一化；标题/正文关键词不计分。得分为已校核标签集合的Jaccard交并比，使用精确分数；解释返回共享、仅查询、仅卡片标签。相同分数按cardId升序，零相关不补足5条。不生成来源、事实、机制或责任结论。

**实际schema没有事故机制枚举**。测试使用者明确提供的reviewed_vocabulary只是合成研究词表，不是新增业务字段、模型抽取或生产已审核机制；词表之外的标签、空值不算匹配。相同标签并不证明事故机制相同。函数不验证完整卡片/来源/权限；正式集成前必须由获准人工逐卡核查标签含义及适用范围，形成可版本化的受控词表，并从真实服务器授权的已发布Case查询取得候选和固定版本，重新检查撤回状态。不能信任客户端JSON的Published来产生可见权限。本次没有实现上述接线或持久化。
