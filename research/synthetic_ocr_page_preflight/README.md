## Separate checks and boundaries
1. Physical page identity requires original PDF SHA, exact PNG SHA mapped to page, and dimensions. A same-size page-2 PNG claiming page 1 is rejected before text/polygon checks.
2. Literal text equality is a separate diagnostic. The page-1 string 08:30 matches a target string but has no page-2 cell assignment.
3. Cell containment uses original-PNG coordinates and strictly convex ordered synthetic quadrilaterals. Every vertex must lie strictly inside a cell; crossing or touching boundaries is unassigned. This is a conservative containment control, not a recognition score. Swapping the string without moving the polygon does not move the cell.
4. No trusted inverse transform is supplied by this preflight. PDF localization therefore remains page-only with originalPdfPolygon=null, even when raster-cell containment succeeds. Future OCR polygons from crops/deskew/rotation cannot be treated as original-PNG coordinates without a separately verified transform chain. No such OCR adapter is provided here.
5. OCR status remains not_run and scores=null. No fabricated engine result, reviewer signature or professional claim.

Tests also reject changed source/render bytes and malformed polygons, and verify inputs are unchanged. Future work requires actual approved OCR output, raw polygon coordinate conventions, verified preprocessing transforms, and independently reviewed recognition/semantic assessment. Exact rendered identity and cell containment are not evidence truth or semantic support.
