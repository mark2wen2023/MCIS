# S2 工程图 → 结构化几何

运行环境为离线 Python 3.13，依赖见 requirements.txt。直接输入一份 DXF 或含 DWG/DXF 的目录。DWG 由本机已安装的 ODA 或 LibreDWG 解码。工具保存原 DWG、转换器和派生 DXF 的摘要。图纸版次改变后应重新提取。CLI 不接受历史答案、图纸句柄或个船配置。

```sh
python scripts/s2.py run /path/to/drawings --oda /path/to/ODAFileConverter --out /path/to/new-run
python scripts/s2.py geometry_data_validate /path/to/new-run/geometry.json --out /path/to/new-check
```

| 子命令 | 输入 | 输出及证据 | 失败或适用条件 |
|---|---|---|---|
| drawing_inventory | 原件 | 源 SHA、图种、比例文字、图签、局部区域、多布局、主尺度 | 仅有标题时给出锚点；边框可能含多个视图；相同主尺度只能建立候选关联 |
| offset_table_extract | 原件 | 按站与字段定位的 cells、原文字、块实例地址、图面位置、表头、边界、单位与米制值 | 争议、合并及边界占位返回未知；独立布局没有文字单位绑定时保持空值；轴标题不可唯一定位时登记缺项 |
| hull_curve_extract | 原件 | geometry 中的实体原参数，samples 中的派生纸面点，kind、confidence 与候选解释 | DWG 的可读参数取自指纹对应的转换件；控制点生成或替换须由另一 CAD 内核独立核验 |
| drawing_alignment | 原件 | 每一视图的刻度、基准、正反轴候选，或通过留一验证的控制矩阵 | 无面外坐标或不明舷别时不发布确定船轴 XYZ；不相容控制点进入 conflict |
| geometry_data_validate | geometry.json，也可用原件 | Schema、来源、单位换算、未知项、重复地址与控制点回投检验 | 输入不合契约退出 4；valid 表示契约和证据自洽，识别覆盖还应检查 inventory.coverage_warnings |
| run | 原件 | 完整 geometry.json，含跨图关系与耗时 | 工具错误与部分可用结果共同保存；请始终使用新输出路径 |

五项投影各自用同名命令执行，例如 `python scripts/s2.py offset_table_extract drawings --out new-table`。一次性生产交付物使用 run。型线数据供曲面算法读取，不在本阶段自动放样。

## 下游读数

1. 用 source_sha256 定位原图，用 layout、handle 和 instance 定位原始实体及其块插入路径。原生 ACAD_TABLE 用表句柄和行列索引定位。单元位置不可独立恢复时保留 null。raw_texts 保留打印内容；value 是数值解释，value_m 另记单位依据；blank_unknown 与 zero 不能互换。
2. geometry 的控制点、拟合点、节点、权重及凸度属于对应 CAD 表达。嵌套块自带 ezdxf 行向量变换。samples 已变换到图面 WCS，只作索引与几何比较。拟合点逐项相等还需另外检验曲线之间的连续几何。
3. 三维矩阵采用列向量。变换公式为 `ship_xyz = paper_to_ship_m @ [paper_x,paper_y,1]`，单位米。ship_coordinate_candidates 可能同时列出两种横向符号，保留固定轴、标定残差与工程观测；ship_coordinates 只给有明确控制证据且落在控制区域内的点。相同轴的重复观测不能证明缺失轴或舷别。
4. 自然图纸通过实际 CAD 栅线、站距、基线/中心线以及不同视图查证。显式控制文字支持 `CONTROL 名称 X=数值 Y=数值 Z=数值 m` 或 mm，其插入点须为对应控制点。在同一布局内为不同视图使用独立块实例或独立布局。每组需至少四个点，留一子集满秩且最大误差不超过 0.00001 米。布局级单位声明只在对应布局使用。
5. 表头尺寸组与其他图纸尺度交叉核验产生研究候选。毫米制换算正确也可能有局部原文和实际曲线矛盾。正式采用须使用同版工程证据；不得仅凭类别标签、近邻注字或单张图上的轮廓来推断完整实船。
