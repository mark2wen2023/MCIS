# S4 内部构件预研

原有 scripts/parts.py 的 discover_parts 与 extract_parts 读取带角色图层和船轴依据的 CAD 三维面。extrude_registered 可对封闭二维轮廓按有单位的尺寸注记挤出，并检查封闭性。本阶段继续调用上述挤出和质量检查。新增 scripts/s4_structure.py 负责跨图构件登记、正交投影核对及与给定船体的空间测量。

输入为包含 DXF 或可本地转换的 DWG 的目录。当前支持直接绘于模型空间的凸封闭 LWPOLYLINE。图内以 PART 标记构件编号和类型，DRAWING ID 与 REF 建立跨图关联；两视图分别使用至少四个显式 CONTROL 控制点。主视图须有唯一的 THICKNESS 或 HEIGHT 米制尺寸及 NORMAL 有向船轴标注。独立视图需在自身控制域内给出可核对的投影。支持类型见脚本 ROLES，甲板、横纵舱壁、肋骨、纵骨、强横梁、加强筋、舱室、舱柜与双层底板均有正例。双层底单板不能代表整座双层底结构，复杂型钢截面需要新增证据。

运行 python scripts/s4_structure.py input --out new-result，可传 --hull-glb 指向按工程 GLB 约定导出的船体。结果含原图摘要、构件和控制点句柄、尺寸、船轴边界、逐面来源、构造方法、缺项与质量结果，通过项附米制 PLY。独立侧视投影的边界距离阈值为 0.01 mm。给定已验证闭合船体后，另列顶点到壳体的最近距离及落在阈值内的顶点数。该距离无法证明焊接或推导连接强度。缺失材料、焊接方式及复杂连接保持未知。

出版习惯不同的常规二维结构图尚需研究文字指引、局部视图、块内标注与型材剖面。三维构件试验使用合成船体。返回 4 表示没有受支持构件或至少一项阻塞，详情见 structures.json。
