# S4 工程结构图提取与局部三维成品

从图纸目录运行。DWG 需本地 ODA 或 dwg2dxf，DXF 直接读取。每次指定新的输出目录。

```sh
python scripts/s4_structure.py drawings --mode observe --out observation-run
python scripts/s4_structure.py drawings --out modeling-run --oda /path/to/ODAFileConverter
python scripts/s4_validate.py modeling-run/structures.json
python scripts/s4_hull.py hull.ply compartment.ply --role compartment --out compartment-check
```

## 怎样读交付结果

|结果字段|可以使用的内容|需要保持未知的内容|
|---|---|---|
|observations|原图与转换件指纹、实体和块实例、原文、纸面锚点、板厚与型材、显式肋号／区间、标注的重复规律、托线和引线箭尖。印刷单位可为空。|未给的材料和板厚、仅靠阵列文字推测的实例、绝对船轴位置。|
|view_titles、identity_candidates、profile_matches|对照视图标题、构件标记、跨图规格，查看同名或同规格候选、冲突及版本。|相同规格或相邻图中文字重名均无法唯一证明是同一根构件。|
|section_templates|角钢或扁钢的名义截面轮廓与原图规格；复合注记按型材前的构件词分配。|轧制圆角、安装长度及缺少单位的米值；截面不计为已建实体。|
|local_models|从一根引线关联到有真实边界的板面，以原图纸面局部轴生成闭合 PLY。检查尺度、厚度单位依据、实际板边是否落在编号肋位及其支持刻线。|绝对船轴、左右舷、安装正反面、焊缝、实际孔洞。厚度单位采用同图佐证时按研究假设交付。|
|components|以两个互相引用且具备控制点的视图校核。可从同名构件的独立投影确定挤出方向。两个视图不一致时列出拒绝原因。|缺少尺度、尺寸、唯一轮廓、跨图指认或视图配准的整件。|
|conflicts|同一位置和同一指向实体上的尺寸矛盾。区分长板同一图线不同位置的局部厚度。|不能将一个箭尖的厚度自动扩展到整块板。|

默认 model 入口在能生成局部候选且没有待处置的显式整件、或已登记整件全部通过时退出 0。observe 模式对提取得到的观测返回 0。其余返回 4。两者均写出结构数据；运行成功不能代替检查各构件状态。JSON 契约在 schemas/structures.schema.json。缺失三维真值时按构件逐项报告。

## 船体接口

输入须共用船轴右手系与米制原点。PLY 按船轴读取，GLB 复用既有交换轴变换。使用 libigl/CGAL 对闭合实体作交、差，核对体积守恒及裁切成品质量，并区分分离、边界接触、部分穿出及包含。共面接触面积通过接触三角形投影裁切计算，点接触、线接触的面积可为零。舱室的 closure_verified 仅表示输入几何满足闭合条件。接触不证明焊接、连通关系或实船水密。微小薄片可能触发原有几何质量阈值，明确拒绝后保留回执。

成品写入双精度 PLY，并回读顶点及面。独立验证入口校验文件指纹、实际闭合与体积、船轴构件的包围盒；局部板重新按有来源的轮廓与厚度生成并逐顶点核对。需要确认资料真实性时仍须独立回到原图。

## 适用范围与继续研发

现支持原生 LEADER、具有实心箭头的折线以及文字托线接折线的常规画法，支持文字旋转及块实例；跨图放置仍要求适用的正交投影和有来源的坐标控制。直边局部轮廓能由原图线段围合时可求板面。对开边、带孔、多候选、曲边及大面积整层甲板继续保留观测。舱壁、骨架和舱柜的整船拼装需下游经验证的局部空间变换、完整截面、端点、边界及舱体拓扑。实船报告与源图按私有目录保存，公开工况、失败记录及复现方法见 benchmarks/s4-blind。
