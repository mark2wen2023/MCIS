# 结构证据与局部安装

入口读取一个仅含同一研究对象 CAD 图纸的目录。DWG 指定本机 ODA 转换器。输出目录必须是新目录。下列命令在 Skill 目录执行。

```sh
python scripts/s41.py drawings --out new-run --mode observe
python scripts/s41_validate.py new-run --source drawings
python -m unittest discover -s tests
python benchmarks/check_s41_frame_scope.py new-scope-results
```

对 DWG，在前两条命令追加同一组 `--oda /path/to/ODAFileConverter` 参数。实体和面保存在 structures.json 及其引用的 PLY 中，关系见 evidence-graph.json。--mode observe 返回成功表示抽取到注记。交付几何还须独立读取模型和重放原件。数据格式见 schemas/structure-evidence-4.1.schema.json。

从 annotation 的原图摘要和块实例开始，沿引线、箭尖和原图边界复查候选闭环及厚度依据。每一条关系使用 direct、derived 或 candidate 标明依据。同一规格可属于不同构件。局部投影相接时保留原曲线参数、残差和投影位置。焊接、实体身份及未知的横向坐标需要各自的证据。

installations 中 partial_xz 保存从指定肋位向递增方向的偏距、从基线朝剖面一侧量取的高度；全船纵向原点、横坐标与厚度方向分别核验。arrays 保留点名肋号、适用区间、重复规则及推算列表。缺少相位时保留空值。舱口投影的原弧和原直边可以追溯，围板厚度另行核实。

复验先执行格式与成品读回，再以相同图纸和转换器重算整幅证据图。缺边、重边、歧义基线和无单位板厚分别查看 chains、installations、structures.json 的 issues 和原始观察。S3 接收端还需检查图纸版本、GLB 船轴和几何验证依赖。
