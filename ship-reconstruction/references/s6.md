# 统一船舶重建与坐标交接

在 Skill 目录执行下列命令。DWG 增加 --oda 和本机转换器路径。可用 --local-reference 提供具备源图指纹和未知横向位置说明的局部剖面 GLB，入口会按原图重新生成各件并逐节点核对顶点。读取 manifest.json 核对各项研究成果或受阻原因。

```sh
python scripts/s6.py drawings --out new-result
python -m unittest discover -s tests
```

| 数据 | 坐标与读法 |
|---|---|
| S2.1 geometry.json，S4.1 structures.json 和 evidence-graph.json | 沿用各字段声明的图面 WCS、局部板轴、船轴候选或相对肋位投影。原图和尺寸来源随记录保存。 |
| hull.glb | 船轴右手 X 向艏、Y 向左舷、Z 向上，或受限的对称局部船轴。顶点以米计，先减去精确原点，再转为 glTF 的 (x,z,−y)。asset.extras.coordinates 与清单同步。用逆旋转恢复后再加原点。 |
| 局部构件 GLB | X 表示沿肋号递增的偏距，垂直轴表示距基线高度，厚度以演示中面对称显示。frame_section_display 与 vessel 之间缺少的刚性安装变换保持未知。证据支持完整安装前，模型单独交付。 |
| 设备 GLB 与设备 JSON | 关节原点属于父坐标系，单位轴属于关节局部系。标准导出同时旋转局部顶点、共轭变换节点矩阵并转换关节参数。每个 GLB 含交换声明，每份关节 JSON 绑定 GLB 摘要。使用 s6_equipment.intake.read_articulation 读回。固定构件拥有独立节点。 |
| 旧剖面展示 GLB | 只接受与原图来源、逐节点几何及未知安装状态相符的参考，原样保存，禁止再执行船轴到 glTF 的旋转。 |

S5 的设备图入口识别显式 EQUIPMENT 注记，使用合成模板和约定轴。只有已明示共同原点的合成实验才使用 --synthetic-common-datum。实船遇到自然标注时须核对设备专图、轴线和安装位置，未知限制保留空值。S3 只支持上游已准入且附明确封盖证据的对称域。局部对称船体不能进入船轴设备装配。跨分项统计应注明目标及分母。

源版本为 S4.1 bedd9fd、S3 c9883e3（历史补丁独立提交 a247407）及 S6.3 b546eda。设备模块保留绘图解析、参数构件、关节控制、固定结构连接及标准导出，整合版本采用包内导入。S3 基准步骤见 benchmarks/s6/README.md。原始冻结包与完整离线回执可在授权本地环境复验。
