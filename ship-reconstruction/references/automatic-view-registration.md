# 自动视图配准候选

沿用 S2 入口。运行 `python scripts/s2.py view_candidates <图纸目录> --out <新目录>`。DWG 可指定 --oda。此入口只读取 CAD，不接受设计专用配准表。每个来源和布局分开登记，未能得到候选时保留空列表。投影名 XY、XZ、YZ 分别表示半宽平面、纵剖侧视和横剖视图。

布局首先经 `cad.read` 展开为原始实体实例及曲线、文字、引线、箭头和表格记录。`view_registration.partition` 在这些记录上建立二维包围盒空间索引，以实体间距构建候选连通簇；长直线不参与跨图元连通，以免尺寸线或图框桥接不同区域。随后按距离将长线、文字及引线关联到最近区域。跨越多个区域的图元放入 `cross_region_handles` / `shared_handles`，版框放入 `drawing_frame_handles`，未能关联的句柄保留在 `unassigned_handles`。

每个区域含稳定的 `region_id`、原布局坐标系边界、原始 CAD 实例句柄、种子句柄、跨区域句柄、线方向族、标题证据和视图类型候选。视图名称附近的明确文字可形成强候选；缺少标题时，XY/XZ/YZ 只以低置信度并列输出，不从几何外形猜成确定视图。区域边界重叠或多个标题落入同一区域时会显式标记歧义。文字宽度不由估算字符长度替代：区域索引只用文字插入点，避免长段注释把视图边界撑大。

尺寸注记由 S2 的 `alignment.dimension_annotation` 解析后附回所属区域的原始文字句柄。支持米制长度、英寸小数/分数、英尺英寸混写、`94x30in` 这类同单位尺寸对、`1:48` / `Scale: 1:48` 比例标注。成对尺寸只保存原始顺序，不擅自解释长宽方向。`unit_evidence` 分开记录打印尺寸单位、显式单位声明、CAD 文件头单位和纸面比例；文件头单位不等于图纸比例换算。来源冲突会标记 `conflict`，不以多数值消歧；未知单位及比例继续保持未知。

空间阈值按该布局文字高度及非退化图元尺度估计，属于候选分区参数，不是视图分类准确率或概率。零长度 LINE 不参与空间簇及阈值统计，但句柄保留在 `unassigned_handles`。较长折线片段只有落在有效线段长度分布内才参与分区，过长线不跨区域连通。实际图纸仍可能出现漏分区、拆分或重叠；检查 `shared_handles`、`unassigned_handles`、`overlap_status` 与区域可视化后，才能决定是否适合进入配准。

points 是证据排序分，无概率含义。双轴等比例并有刻线对应的投影优先；名称和线族只支持视图假设。paper_to_label 将纸面位置换算为印刷标签的数值；例如站号每增加一格，物理间距仍可能未知。axes_m 是 S2 已有的米制候选，单位和方向依赖见 rulers、unit 和 unknown。站号增长方向不自动等于向艏方向。原点的纸面投影、实船零站所在端、左右舷符号和面外坐标需分别举证。多图相同刻线编号或间距仅提供一致性检验。当前不自动将候选写入重建或运动配置。
# 局部坐标注记拟合（A09.3）

区域内出现带明确单位的 `X=..., Y=...` 注记时，S2 先登记原始文字及句柄。注记插入点不被当作几何控制点。只有显式关联的引线顶点落到 CAD 几何线上时，才可将该几何位置作为候选控制点；变换仍不证明标注坐标就是船体坐标，也不确定艏艉、左右舷、基线或图纸版次。

缺少几何关联时标记为 `annotation_only_unverified`，不生成变换矩阵。几何控制点少于四个或几何一致性不达门槛时分别标记为 `insufficient_geometric_controls`、`insufficient_consensus` 或 `low_confidence_candidate`。内点比例、留一误差虽过门槛也只保留为 `candidate`，不得标记 `verified` 或用于安装坐标。单位未明确时不拟合。

# A09 有限整改：碎线、视图分值和跨视图检查

`_fragment_chains` 将非退化 LINE 视为候选边，以端点距离阈值、互为最近邻和切向转角（默认不超过 25°）连接；保留源句柄、总长、PCA 主方向、最大转角及单位长度转角代理。分支处只保留互选的平滑连接，直角构件不自动并入船体轮廓。恢复曲线是诊断候选，不改写原始 CAD 曲线。

视图区输出 `view_geometry_scores`，记录主轴长宽比、配对轮廓对称性代理、肋位标签数、基线注记和坐标注记惩罚。评分只用于排序；`ambiguous_candidate` 与 `weak_ranked_candidate` 均为低置信候选，不能获得建模或安装准入。权重是研究启发式，不能解释为校准概率。

坐标文字的插入点只作为注记位置保存。只有引线明确关联该注记，且引线顶点落到 CAD 几何线上时，才作为候选控制点参与拟合；缺少这种关系时输出 `annotation_only_unverified`，不生成变换矩阵。`crosscheck` 对不同区域共享的肋位/水线标签比较纸面刻度间距；没有足够共同标签时输出零项检查，而不是推定一致。该比较只检验相对纸面比例，不授权单位、船轴方向或安装坐标。
