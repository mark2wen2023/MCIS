# 能力、契约及质量门槛

| 输入与条件 | 输出 | 验证及适用范围 |
|---|---|---|
| 原 DWG/DXF、可选本地转换器 | 文件及图元摘要、单位、图种、文字句柄 | 转换成功只证明图纸可读。未展开块及二维符号需另外核查 |
| 有显式站位、高度、单位及船轴的单表，或有来源的配置 | table.json、offsets.json 与原始空格 | 旋转与镜像由表头定位。多候选、冲突、改版摘要进入待补证 |
| 带矩阵、句柄及用途的横剖、水线、纵剖 | curves.json、逐面证据、留出残差 | 横剖和水线可约束半宽。纵剖可提取和留出验算。完整艏艉外推与多值截面仍需单独建模 |
| 稀疏半宽网格 | contact.glb、逐面句柄、可选型值域排水体 | 空格不补零。对称和封盖记录为研究条件。封盖可能只代表表格范围 |
| 同版原设计 STL、配准和有界训练曲线 | 经验证的辅助研究候选与原型值开片 | 单一闭合原体、正向体积及独立无自交检查。留出曲线独立于拟合 |
| 有图层身份与船轴的 MESH/3DFACE，或配准的二维闭合轮廓及厚度/高度文字 | 构件节点、单件 GLB、逐面源句柄、舱室闭合检查 | 语义图层支持自动归类。二维挤出仅适用于登记法线和恒定截面。二维符号、变截面连接和跨图舱界仍需注册 |
| 单一闭合壳 | 排水 GLB、分吃水体积/浮心/水线面积、凸包代理 | 代理是粗筛凸包，报告体积增量。全域高度之外报告水线面积的可用性 |
| 验证过的面 | 展示组合 GLB、S3 候选 INP | 有限元输入只含节点与单元。材料、厚度、连接和支承需额外核实 |
| 独立合成工程图与预注册连续真值 | 八项几何测量及通过状态 | 正常入口生成模型后由独立程序读回。两个样本的覆盖范围须在报告中明示 |

GLB 预算为每顶点 0.1 毫米；每边绝对误差限为 0.0000001 米加边长的千分之一；每面面积限为 0.0000000001 平方米加面积的千分之一。法向点积须为正。这些属于交换精度预算。真实船体精度还须通过未参与拟合的观测验收。来源覆盖率按逐面与逐构件分别统计。缺失构件及没有独立真值的项目单列。
