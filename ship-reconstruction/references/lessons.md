# 从原始图纸到验收的经验

| 工作环节 | 实际观察到的失败或识别条件 | 恢复办法与应留证据 |
|---|---|---|
| 图纸分类及版次 | 总布置尺寸、稳性计算和型线的长度口径可能不同 | 比对图名、图签、垂线和量取范围，保留候选版次及摘要 |
| DWG 转换 | 模型空间实体计数相同，引用块仍可能变空；不同内核也可能重排样条或凸度 | 对照块定义、嵌套实体、变换与曲线同址采样；只授予已核范围 |
| 表格与单位 | 旋转、镜像、空表头及行列互换可改变对应关系；图面毫米与文字型值单位可以不同 | 用文字锚点建立可逆局部坐标，分开验证表头、文字单位、船轴与基线 |
| 稀疏型值 | 空格的语义因位置而异，原表存在真的零值 | 原文与派生值分列；原图曲线反算保留句柄、定位和冲突。有多个交点时保留未知 |
| 曲面与光顺 | 站间截面快速变化时加密三角面仍可保留原偏差；穿过训练点的光滑曲面也可出现曲率尖峰 | 全曲线留出，在固定测站比较半宽、曲率、剖面面积和分吃水体积 |
| 艏艉与边界 | 用中段同一种插值推到端部，可能改变上缘或翻面 | 原水线单列，对局部候选按区域复核，比较双向距离与静水力，保留旧版 |
| 构件与舱室 | 总布置符号与一张剖面的轮廓不足以确认横向连通、板厚或纵向终点 | 关联封闭轮廓、单位、剖位及范围证据，单独校验每个舱室的闭合性 |
| 排水实体 | 展示网格可带开口、多个零件和外观附件 | 单独核验排水体的边、顶点流形、方向、自交、封盖与坐标，再对照不同吃水 |
| 模型交换 | 文件格式合法仍可能出现 float32 顶点重合、面退化或法向翻转 | 读回导出件，按对应顶点、边和有向面积验证。失败保留原输出；必要时回到原设计拓扑 |
| 网格修订 | 硬拉到训练水线会压塌窄三角形；单位正确也会发生 | 撤回涉及翻面的局部修订，必要时采用原拓扑上的有界残差插值；整壳和留出证据重新验收 |
