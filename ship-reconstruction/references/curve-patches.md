# 多视图配准与研究曲面

配准配置是 UTF-8 JSON，根字段 regions 为数组。每个区域提供唯一 id（字母数字、下划线或短横线）、frame_evidence、递增 stations_m 和 curves。每条曲线含原件 source_sha256、原生 handle、source 描述、kind（waterline、section、buttock）、use（constraint 或 holdout）以及纸面 WCS 到米制船轴的可逆 4×4 matrix。必要时用 fold_halfbreadth=true 表示无符号半宽。原图 CAD、指纹、所标高度和站位的配准记录应单独归档。

每个区域至少需要两条不同高度的水线。同站横剖可作为交叉约束，纵剖及其他独立曲线参与留出。区域之间的材料不自动连面；同格遇到多值、冲突或少一个角点即留空。程序读取旧式 DXF 的拟合多段线时使用 CAD 保存的拟合顶点，保留控制多边形和拟合几何的区别。配置需由有依据的上游提供，当前入口不会自动推断未知单位和基准。

输出为应用过船轴到 glTF 交换变换的米制局部正半宽 GLB。每个已交付区域有面序与原图句柄对应、派生值及留出点处的有符号半宽残差；未覆盖的样本保留 null。开放边界没有排水计算资格。遇到折返可凭原图分区，不能通过排序同一条曲线的点去掉折返。即使拓扑和浮点读回合格，超过项目几何误差要求的区域仍须受限。

Unity 查看模板读取经过 SHA-256 校核的图形及目录。基于同一设备 Runtime 的 rotation_samples 生成局部旋转表，客户端仅做 glTFast 左右手转换与插值。连续关节的 RPM 与有限关节的角度都须区分演示范围和实际安装数据。

统一入口也接受 `python scripts/s6.py 图纸目录 --curve-profile 区域配准.json --out 新目录`。整船受阻时，可在同一份封存清单交付局部曲面。whole_hull 保存原阻塞状态，局部片体无整船安装基准；恢复运行须提供原配准文件。
