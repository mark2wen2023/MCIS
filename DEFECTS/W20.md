### W20-D01 KnownDefect: overlapping citations pass uniqueness check

Severity: blocker, source attribution.
`checked_statements` uses str.count, which only counts non-overlapping occurrences. Raw answer `aaaa`, quote `aaa` has two valid starting positions but is accepted. Test `test_known_defect_overlapping_quote_must_be_rejected` fails. Required: reject every quote with more than one matching start, including overlapping matches, in both raw and redacted text.

### W20-D02 KnownDefect: sensitive fragment overlapping name leaks

Severity: blocker, mandatory pre-model redaction.
Raw answer `测试甲患有虚构病症。随后右满舵。`, interviewee `测试甲`, sensitiveFragments `["测试甲患有虚构病症"]` yields `<ROLE_01>患有虚构病症。随后右满舵。`. Name substitution precedes fragment matching, so private fragment remainder survives. This gateway behavior predates W20, but W20's newly connected model egress inherits it and must fail closed. Test `test_known_defect_sensitive_fragment_overlapping_name_must_not_leave_private_text` fails. Required: redact all sensitive fragment source ranges before changing names, including overlapping fragments.

### W20-D03 KnownDefect: Modified accepts non-finite / malformed Unicode

Severity: blocker, accepted-data integrity.
Independently reproduced implementer's reported concern: Modified payload containing scalar Infinity returns 200 and appends a statement; lone surrogate summary returns 500 instead of clean validation. Two parameter cases in `test_known_defect_modified_invalid_json_rejected_atomically` fail. Required: reject invalid/nonfinite JSON and malformed Unicode before mutation, leaving PendingReview and original statements intact.
