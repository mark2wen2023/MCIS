## D01 — fast navigation/Back allows late package-check response
Status: open; severity: medium (stale UI / navigation isolation).

Reproduced with the frozen PackagePanel.tsx on 2026-11-12 using real Chromium and a deliberately delayed packages:verify response:
1. In lobby select a trusted test package; start precheck.
2. Click Enter case. Wait only for URL to become /evidence?case=..., not component commit.
3. Fulfil previous precheck with caseId LATE-OLD; immediately Back.
4. Lobby retains open form and renders LATE-OLD success report.

Evidence: tests_acceptance/W83/after-back.txt / after-back.png (local artifacts). Original browser test timed out waiting for the closed-form button; inspection proves this was not merely an assertion issue. Keep a fast navigation regression asserting LATE-OLD absent. A separate normal visit→Back scenario should also run.

Cause: useOperation cancels on identity change/unmount only; URL/history can change during React transition before unmount. This violates the W8.3 specification that page changes destroy pending results.

No implementation changed by acceptance agent.
