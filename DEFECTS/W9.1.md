## D02: narrow viewport topbar expansion, open

Independent baseline comparison disproved the initial attribution as an unavoidable shared boundary: with the exact same long case title/ID, Ships expands the 768 px document to 1025 px while existing Evidence stays 768 px. Existing W4/W7 styles contain page-scoped `.app:has(.w4-page)`/`.app:has(.w7-page)` grid/topbar wrapping protections. A W9-only equivalent can fix this without changing shared layout globally. Keep the no-horizontal-overflow assertion and rerun with the exact same case.
