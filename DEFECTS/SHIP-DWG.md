# 7388 四 DWG 独立验收记录

冻结实现 fb00b09 的三项文件校验均匹配。独立进程在禁网环境对四份原始 DWG 执行正式入口，并分别调用原生解码器和转换器。四份派生 DXF 相对于独立重转件的哈希均相同。实现自测及独立复核的默认退出码均为 4，限定模型空间的自测退出码为 0。

**模型空间限定通过，整图验收未通过。** 40469 个直接实体、2051 个文字、433 个标注，以及型值表 201 个明确数值、25 个站号、16 个表头和 44 条表格线复现。真实 DXF 的私有故障检查副本中，数值改写、标注覆盖改写、线段起点移动均被检测到。

**KnownDefect DWG-01** 型线图一个被引用的块在 GNU LibreDWG 0.14 转换件中为空，共 1404 个原句柄缺失。三份其他图在相同的句柄存在性检查中没有此类缺失。另一路转换件保留该块，但对四图中 322 条拟合样条生成另行派生的控制点和节点；不能将补出的控制点作为原图数据。转换件不能作整图保真签署依据，仍须同版出图复核。本次没有修改生产解析器，无原始图纸或转换件入库。
