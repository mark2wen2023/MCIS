## W203-D01 — malformed citations counted as references (medium, open)
The overview validates citations only as a nonempty array and displays `.length` as reference count. Entries `null`, `{}` or `{quote:42}` therefore display “1 reference” although they are not citations under `contracts/schemas/common.schema.json#/$defs/citation`. This violates the slice's strict metadata/invalid-batch fail-closed promise. Validate each citation's existing shape before counting; do not display the quote. Reject the complete queue if any entry is malformed. Independent regression: `tests_acceptance/W203/metadata_acceptance.ts`.
