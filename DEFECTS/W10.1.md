# W10.1 independent acceptance

## D01 — rapid navigation/Back accepts old read response (open)
Severity: medium. Frozen TrackPage only aborts on effect cleanup and identity changes. During React navigation transition before unmount:
1. Start a read with tracks response held.
2. Click 返回案件大厅, wait for URL #/lobby.
3. Fulfil old tracks with a distinctive source label LATE-OLD.
4. Immediately Back to track page.
Expected: no old response. Actual: LATE-OLD appears. Independent browser test `fast Back no stale response` fails. No production code altered by tester. Preserve the rapid test, do not wait for unmount to hide this race. Any repair must allow a new read after aborted navigation rather than leave permanent loading.

## D02 — metadata arrays outside point budget (open)
The 50000-point limit does not bound vessel or track-bucket count. A response containing very many zero-point vessels/buckets passes and creates arbitrarily many select options. This is an interface resource boundary, not a maritime-business rule. Recommended separate 1000-entry budgets for each metadata list; reject entire response with explicit metadata-budget message, not the point-limit message. Not a backend security or resource-budget solution.

## D03 — D01 repair cancels newly arrived case reads (open)
Reproduced twice: navigate normally from #/track?case=QA-TRACK to #/track?case=QA-EMPTY using a same-document hash navigation. The new component subscribes before the arriving hashchange/popstate dispatch, then unconditionally cancels its own initial read. Page shows “导航或身份变化已取消读取” rather than the actual empty-case result; .w10-case remains absent for 30 seconds. Local evidence goto-failure.txt/png. Original v1 loaded this case correctly.
Independent navigation.test.ts also reproduces: subscribe at current URL, dispatch an arrival hashchange without any subsequent URL change, callback incorrectly runs. Capture subscribed URL or equivalent bound route identity so only departing history events invalidate this subscriber. Preserve cancellation at outbound link intent and pagehide, and original rapid Back protection.
