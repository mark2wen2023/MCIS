# 评审交件说明

本目录用于向评审员转交盲标材料。其中笔录为虚构合成草案，不是正式验收，不含期望答案或分数。

## 内容

- `transcripts/`：六份笔录原样（IR-SYN-01 至 IR-SYN-06）
- `SHA256SUMS.txt` 与 `roster.csv`：文件名单与 SHA-256，用于核对应固定原件未被改动
- `templates/statement-extraction.csv` 与 `statement-extraction.json`：陈述抽取/出处空白表
- `templates/contradiction-review.csv` 与 `contradiction-review.json`：矛盾评审空白表
- `templates/policy-freeze-denominator.csv`、`policy-freeze-miss-and-false-positive.csv`、`policy-freeze-dispute.csv`（及对应 JSON）：分母、漏提/误提、争议裁定的口径冻结空表

## 使用步骤

1. 按 `SHA256SUMS.txt` 核对六份笔录文件。
2. 先填写口径冻结空表并完成冻结，再开始标注。
3. 在陈述抽取/出处表中填写笔录 ID、问答 ID、证据定位（问/答字段及原文出处）和陈述类型等栏，勿预先填写他人答案。
4. 在矛盾评审表中填写对照来源 ID、版本或摘要、对照定位、结论、不可比较原因等栏。

## 关于矛盾评审表

目前尚未取得独立对照材料。该表只备格式，暂不能打分。本包不提供对照真值，请勿生成或猜测对照数据。

请勿改动 `transcripts/` 中的原件。本说明不含评分规则的既定答案。
