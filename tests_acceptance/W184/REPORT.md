# W18.4 人工 HFACS 草稿：独立验收

验收范围：固定 Draft / ToBeVerified / Investigator 的人工分类草稿，不是事实确认、人员归责、自动智能体分析或官方海事分类标准认证。仅合成案件，seed_demo=False。

## 结果

独立 32 项测试通过：14 项实际 C# CLI、18 项实际 API/数据库测试；另完成真实浏览器 → 服务 → CLI 保存生命周期联调。无新增产品缺陷；未改实现，无删除或弱化失败断言。

- 全部 32 个项目分类含根/分组/叶节点由真实核心返回及校验。批末非法分类/重复 ID 整批失败，无部分成功结果；拒绝状态、来源类型及 ECFC 注入、重复 JSON、非法 UTF-8、孤立代理码位；三个文本字段分别检查 1000 Unicode scalar 边界。
- 独立计算保存 digest。新建第二个服务实例使用同一临时数据库，真实重开返回相同草稿。新版保存后重试旧请求返回原回执，不覆盖当前新版。
- 审计已 flush 后、请求回执插入时、事务最终 commit 前三处注入故障，全部业务表恢复原状；解除故障后同请求成功，只有一次审计。
- 双实际 CLI 请求同步到达写入：相同 requestId 幂等返回一次版本；不同 requestId/相同 expectedDigest 恰好一个成功、一个 409。不同内容或操作者复用请求拒绝且不写入。
- 源元数据、案件信息及政策在核心计算后变化被拒绝；已保存来源变化不静默重绑。当前草稿不含历史来源时，隐藏的历史来源仍阻止审计读取。审计权限与四端点角色/存在性隔离检查通过。
- GET 不改变任何表；审计仅返回摘要。独立重算两条真实完整审计记录的哈希链；数据库拒绝审计删除及请求回执修改。
- 浏览器真实保存已 commit 后，将返回响应替换为 503：显示待核对、锁定输入、不误报成功；同一请求重试后仅一个版本及一条审计。重新打开读取实际保存内容。
- 已 commit 的真实迟回复在换案及换身份后不能恢复旧结果。另一进程真实撤销当前权限后，已打开的编辑器保存收到 403 并隐藏草稿/来源。

已在真实页面确认醒目声明：草稿尚未纳入案件包导入/导出，保存仅在当前服务数据库。

## 复现

配置已有 SDK 的 `MCIS_DOTNET`、可写 `DOTNET_CLI_HOME`，及已有 Chromium 的 `MCIS_BROWSER_BIN`，从仓库根目录运行：

```sh
PYTHONPATH=service service/.venv/bin/pytest -q tests_acceptance/W184/test_cli.py tests_acceptance/W184/test_api.py
python tests_acceptance/W184/browser_real.py
sha256sum -c tests_acceptance/W184/verified-impl-sha256.txt
```

CLI 原源码对照测试需要保留旁边的既有 `mcis-w144` 验收基线。浏览器运行需要 Python Playwright、现有浏览器及前端依赖，服务与前端仅监听 localhost。公开文件仅本报告、两份测试、browser_real.py、server.py、哈希清单；不发布 local 日志。
