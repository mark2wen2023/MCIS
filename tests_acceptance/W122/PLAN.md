# W12.2 独立验收计划

依据：AGENTS、HANDOFF-STAGE1、W12.2-current-track-analysis 合同、原论文 §3.4/4.5.6、ARCHITECTURE §4.6。后两者的完整系统目标不扩大本切片范围：无风险/责任判断，无船体/天线修正，无插值/外推。

1. 冻结前只读实现并编写攻击测试；冻结后起止各核哈希。
2. 独立临时 SQLite HTTP 测试：所有来源及缺来源原样返回、非虚构flag、严格同刻与时间容差、原点/窗口/索引与文档、5000点双侧预算、无交集不调用核心、输入错误、核心错配/非有限/退化、变更期间结果丢弃、权限撤销、无持久写入。
3. 真实 C#：独立几何公式、40组固定随机向量、相对静止、微小负TCPA舍入0。
4. 浏览器：真实 Chromium + Vite，合成拦截 API，身份/案/输入/模式/pagehide 迟到隔离、重复点击、空错态、散点/2000绘图限制/100明细分页、来源标签与非虚构展示、截图核对。
5. 原 W12 冻结 seed SHA256 始终保持；不触W11，不部署，不提交。旧W12服务/自测仅补充，不能替代独立验收。

浏览器阻碍：正常工具审批后 Chromium 报 socket() Operation not permitted，按负责人要求不换二进制或绕权限。浏览器脚本已准备但不能把静读/单测当交互验收通过。当前不能给完整通过结论。
