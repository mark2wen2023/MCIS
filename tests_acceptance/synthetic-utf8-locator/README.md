夹具在宿主代码中分别固定旧/新原字节 SHA-256；定位函数先验摘要后严格解码。

规则：最多65536字节、严格UTF-8、只支持LF换行。拒绝CR/CRLF、BOM、换页符、NUL、
Unicode行/段分隔符，不转换换行、不规范化Unicode。每条非空白LF行为一个逻辑段，
空白行不编号；非空白行前后空格原样保留。段号从1起，段内start从0起，length为正数；
偏移计Unicode code point，不是UTF-16、字节或字形簇。end均为开区间。
全源字符偏移保留空白行与LF，另给UTF-8字节区间并回切原字节验证。
无可靠页码，所以不输出PDF页码；逻辑段不是PDF/OCR版面或自然语义段。

合法含emoji尾段：源字符[15,22)，原字节[41,63)。负例包括尾段越界、错段/起点、
损坏UTF-8（即使摘要匹配）、新文本冒用旧摘要、提取器加入来源字段、换行/BOM/分页拒绝。
新文本仅用独立新摘要可定位；不将相同尾段视为同一文件。
这是原字节与文本位置的一致性，不是事实/语义/身份/权限证明；未与报告草稿贯通。
无文件读接口、服务、网络、存储、PDF/OCR、公开/真实报告或坐标/轨迹生成。
