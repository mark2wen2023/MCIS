## 变更边界
对照 packet-mapping-main 副本的 router，仅新增 validate_new_source_host，并在 POST create 的旧 validate_content 后、事务开始前调用。旧 validate_content 未修改；归档验证不自动套用新主机语法。现有 IPv6、127.0.0.1、localhost 拒绝行为在作者回归中保留；IDN/单根点正常域名接受。副本无 .git，未把父线程声明的 main pin 独立当成远端核验。
