# W9.2 独立验收

所有输入为虚构验收数据，数据库与浏览器产物均隔离于临时目录。

后端：

```bash
PYTHONPATH=service service/.venv/bin/pytest -q tests_acceptance/W92/test_environment_independent.py -p no:cacheprovider
```

浏览器（先安装/指定可用 Playwright 和 Chromium；不需要真实模型）：

```bash
MCIS_PLAYWRIGHT_MODULE=playwright MCIS_BROWSER_BIN=/path/to/chromium bash tests_acceptance/W92/run-browser.sh
```

脚本自动创建独立数据库并启动只监听 127.0.0.1 的后端和 Vite，退出清理服务；日志/截图保留在临时目录。浏览器使用真实后端，仅“保存回复丢失”由浏览器在服务提交后丢弃响应，核查仍使用真实 GET。
