## 时间、身份与几何

共同 caseId `SYN-XREPO-001`，独立 `SYN-VESSEL-A/B`；窗口 `2026-02-01T12:00:00.000Z` 至 `2026-02-01T12:03:40.000Z`，220秒。
A 所有点 referenced / 0；B 所有点 corrected / +12秒。合成设定 B 源时钟慢12秒，alignedUtc=sourceUtc+12s；B源窗口11:59:48–12:03:28Z。sourceRecordTime 原样保留 sourceUtc，均为合成严格Z且递增。

身份 operator_asserted，引用 synthetic-identity。IMO `0000001/0000002` 的校验位故意无效；MMSI `000000001/000000002` 不符合普通船台MID，仅测契约位数，绝非登记号。参考校验器只检查字符/位数，不认证身份。

两船沿同一纬线相向，A COG90°/10kn，B COG270°/12kn。人工设计使用每纬度60nm及cos纬度换算；独立球面粗验（R=6371000m，1nm=1852m）初距1.801214nm、末距0.455863nm、净收敛1.345351nm；各相邻点的几何平均速率在8–14kn。缺口两端弦长只用于设计量级检查，不是缺口内轨迹或允许回放的证明。

## 缺口及品质

两船 expectedIntervalSeconds:null，实际非等间隔；gapThresholdSeconds:15仅为本试件门槛。
A明确缺口内部 `(60,100)` = `12:01:00.000Z–12:01:40.000Z`（40秒），及 `(121,127.5)` = `12:02:01.000Z–12:02:07.500Z`（6.5秒）。边界均有 recorded 位置，内部无点；禁止跨缺口插值。短缺口两端不在5秒格点，但6.5秒不可能整个落在一个5秒间隔。原目录1秒试件仍用于捕获整段落在采样格点间的已知CPA跨线风险，本轮未运行消费者/CPA。
