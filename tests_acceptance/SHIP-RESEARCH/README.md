# 船舶重建并行分支的独立验收

在隔离目录检出要验收的开发分支提交，记录完整 SHA。使用目标版本的 service 环境及仓库阶段交接文件指定的命令。验收代码通过参数读取目标源树；此目录可由不同模型或人工复核者直接使用。

1. 在目标源树运行船舶专项，再在 service 下运行完整 pytest。两组各自保存命令、退出码和逐例报告；另运行仓库前端及 C# 验收矩阵。分开记录断言失败、启动错误、跳过和环境阻断。
2. 对提供空格语义及坐标接口的版本，运行 `python tests_acceptance/SHIP-RESEARCH/check_offset_contract.py <目标源树>`。该探针使用合成值检查空格保留、证据要求、轴向、单位、坐标转换与放样门禁。输入的纵向距离有长度量纲，原始站号应先凭图纸或站位表转换为距离。
3. 在隔离环境对原图按只读方式调用开发分支的转换、解析、评估入口。逐项记录三者状态。对转换件检查定义和引用、未引用块、顶点顺序和出现次数。展开定义前先查原始组码，避免解析器对缺省值或重复句柄的处理遮蔽差异。
4. 以原格、来源定位、单位和基准作为证据底层。把外部表数值、几何交点、图纸斜线、共用剖面标注和分类候选分别记录。图面的空白保留空值。筛选余量随报告保存并单独做敏感性分析。源版本不符时输出待补资料和待签署项。
5. 虚构基准直接运行开发分支的 hull_benchmark.benchmark() 与 hull_benchmark_complex.benchmark_complex()。同目录 fixtures 为冻结结果，包含 MAE、RMSE、最大绝对误差（米）和评估点数。各指标度量已采样站位上的留出高度，工程精度另需独立验收。

### 合成 CAD 回归

预装 Python、ezdxf 及 LibreDWG 的 dxf2dwg、dwgread、dwg2dxf 后，可断网运行下列命令。

```sh
python tests_acceptance/CAD-INTEGRITY/check_bulge_roundtrip.py
python tests_acceptance/CAD-INTEGRITY/check_bulge_roundtrip.py --bulge-only
```

夹具在临时目录生成一条有正、负、零凸度的经典二维多段线，先在生成的 DWG 中复核夹具条件，再检查 DXF 中每个顶点的每次出现。默认同时检查凸度、标志和出现次数，发现差异退出 4。`--bulge-only` 只用字段一致性决定退出码，报告仍列出出现次数。该实验只读取合成输入。
