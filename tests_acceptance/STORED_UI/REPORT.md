## 审查发现与修正

- 初稿只在上下文失效时递增 epoch，可能接纳同一上下文上一读取尝试的迟到结果。实现者修正为每次保存/读取尝试递增；独立最终测试通过。该初稿缺陷来自静态审查，运行测试前产品已修改，未声称执行了旧稿失败复现。
- 初稿缺少当前 sourceIdentities 与 parentReport/reportSnapshots 的内部关联验证。实现者加入后，独立验证合法父报告正例、错误 hash/案件身份/关系状态/来源性质/摘录来源拒绝。
- saving 状态最初不处理确定的拒绝，可能一直显示保存中。实现者增加 denied/stale/unknown 转换并保留 operationId；最终独立测试通过。未独立执行修改前失败版本。

## 独立覆盖

跨案/错runId/approved状态/写凭证/错误epoch/请求变化/来源hash/未知根字段/核心认证伪标记拒绝；未知嵌套内容不透传。投影与输入分离，不返回原请求/代次封套。缺失当前身份、缺失父快照拒绝。父报告正例仅展示未审核，不生成已验证标记。

重复点击不创建新尝试；未知结果重试必须保留操作ID；迟到读取结果与上下文失效后结果拒绝；读取失败保留已保存编号且不显示旧结果；保存拒绝离开busy状态。

默认组件断开、按钮禁用、显示未审核/未连接身份/非生产提示；React转义摘要中的HTML，不使用raw HTML。

## 边界

独立模块未挂业务路由、无网络适配器/令牌/存储/旧角色头。ExpectedStoredScope 必须由未来可信当前上下文提供，不能由待解析响应自行构造，解析器不是授权机制。SSR测试与纯状态测试不能证明浏览器生命周期、网络取消、登录/IdP/CSRF、整个工作台证据清单或生产安全完成。无部署、推送或合并操作由审查者执行。
