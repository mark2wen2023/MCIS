# DeepSeek 接入：独立适配器与虚构笔录验证

本阶段新增独立远端 transport 和一次性验证 CLI；尚未接入生产案件或受保护工作台 host。原本机模型配置和 loopback 限制不变，不自动选用远端服务。

## 配置与凭据

- 服务端从受支持的密钥环境绑定读取 `DEEPSEEK_API_KEY`，不要在聊天、命令行参数、仓库、浏览器或日志中填入密钥。
- `DEEPSEEK_MODEL` 可为 `deepseek-v4-pro`（默认）或 `deepseek-flash`。
- 目的地固定 `https://api.deepseek.com/chat/completions`，不接受自定义 URL，不跟随重定向。
- 保留可信运行环境提供的 HTTPS proxy 和 CA，以支持托管网络凭据替换。运行环境及其配置属于信任边界，不能把不可信用户的代理设置传入宿主。
- 不自动重试，不下载模型，不启动监听服务，不上传附件，不使用模型工具调用。

## 显式虚构验证

在具有依赖的 service 环境下运行：

```sh
python -m mcis_service.agents.deepseek_probe
python -m mcis_service.agents.deepseek_probe --send-fictional
```

第一条完全不读取凭据、不请求网络。第二条仅使用代码内固定的虚构笔录；无凭据返回 `not_connected`。不支持指定案件、输入文件、标准输入或密钥参数。网络调用失败、格式不合格或引文不匹配均为 `unconfirmed`，不会伪造成功或返回固定提案。输出只有状态、数量及限制，不输出密钥、请求正文或模型原文。该 CLI 不代替案件授权验证。

## 数据和质量边界

提示构造复用强制脱敏；输出复用结构契约和逐字唯一引用检查。JSON 合法不代表事实正确，模型提案仍需调查员审核。JSON 模式可能返回纯空白，即使 `finish_reason=stop`，也必须拒绝。

该实现通过模拟 HTTP 合约测试不代表真实 API 已连通。真实连通必须另记录运行结果，不能将模拟输出、配置模型名或引文匹配描述为模型身份认证或专家准确率。

## 可信宿主显式发送边界

`deepseek_host.describe_egress(...)` 先核对会话、成员权限、笔录、来源及策略，返回需向用户展示的目的地、模型、案件/笔录范围和脱敏发送类型，不含正文、密钥或会话令牌。可信宿主在用户同意后，才可向 `deepseek_host.run(..., approved_disclosure_digest=...)` 提交该范围摘要。

摘要绑定会话、案件、笔录、原文/策略版本、实际脱敏提示、模型和官方目的地。任何范围变化都必须重新确认；发送前与响应后均重新核对来源和权限。默认未选择配置时不连接，配置凭据不会自动启用发送。已发送的数据不能因之后撤销权限而追回；撤销后不返回提案。

**边界：范围摘要不是人类点击同意的证明。此接口仅供可信宿主使用，不能直接接收模型或网页的“已同意”声明。现阶段没有生产 UI 授权交互，也没有将旧工作台自动连接到远端。** 真实部署还需可信登录、批准交互及持久审计。返回仍是未保存的 PendingReview 提案，不自动写事实。

## 2026-11-14 实际验证记录

- 托管代理采用 SOCKS，需 `httpx[socks]`；缺少依赖时请求前失败，补齐后未绕过代理或 TLS 验证。
- 固定虚构笔录：真实官方 API 返回 HTTP 200，2 条提案及 2 条逐字引用通过；未保存至案件。这不验证模型身份、事实或生产 UI。
- 公开报告：[上海海事局公开版报告](https://www.sh.msa.gov.cn/sgdc/104170.jhtml)，PDF 正文第 1 页（PDF 第 3 页）损失段，进行了真实 API 试跑。已明确该输入是报告摘录，不是证人笔录。
- **真实报告段落未通过验收**：HTTP 200 后模型输出的 `scalar` 使用字符串而非数字，引用还省略了原始抽取文本中的换行。严格结构/逐字引用门禁拒绝，没有保存提案。未自动修写引文或放宽门禁。
- 下一步应明确数字字段和引文保真提示，并设计带原文映射的 PDF 断行规范化；必须回归后再验证，不将本次失败记为成功。
- 后续明确提示修复了数字类型及“船体部位不是经纬度 Position”的歧义，**同一公开原段复测通过**：官方 HTTP 200，7 条提案和 7 条逐字引用通过。原始换行未修改，span 使用输入字段 UTF-16 坐标；可从这些坐标回取原文，不是 PDF 视觉框坐标。
- 人工检查确认摘要保留“约 171.053 吨”和“未造成人员伤亡”，没有新增责任判断。当前 scalar 没有独立 approximate 字段，约数仅由摘要和引文携带，下游不得将该标量当作精确测量值。
- 单次真实段落通过不是稳定性、完整案件、多模态或生产登录/审批验收；之前失败记录仍保留。
