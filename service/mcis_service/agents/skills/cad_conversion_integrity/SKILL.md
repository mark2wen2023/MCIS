用在有原始 DWG 与一个或多个候选 DXF 的交接环节。先对所有文件计算 SHA-256，同版原图的转换件逐份独立复核。预置 Python 3.11+、ezdxf 1.4.5 和带 JSON 输出的 GNU dwgread。在仓库根目录运行以下命令，标准输出为本地 JSON。

```sh
python service/mcis_service/agents/skills/cad_conversion_integrity/check.py original.dwg candidate.dxf
```

可加 `--block 原件块记录句柄` 缩小范围。命令直接从 DWG 读取对象关系，查所有 INSERT 引用的块，含嵌套引用、块基点、插入点、缩放、旋转、法向，核对块边界、顶层成员及关联子实体。LINE 检查端点，二维多段线检查顶点顺序、位置、宽度及凸度等，返回覆盖数量及仍未比较几何的类型。该入口针对保留句柄的转换路径；输入缺失、读取失败或检测到差异退出 4。无引用时结果为 no_references。外部参照、阵列引用、句柄重排及未覆盖的几何需人工复核。对全文字、标注、样条和模型空间几何另运行仓库 tests_acceptance/SHIP-DWG/check.py。

### 缺块的定位与修复研究

1. 沿原件中的 INSERT 找到块记录，先核对所属成员和基点，再核对引用变换。模型空间中的引用实体仍然存在时，也要检查定义内容。
2. 在隔离目录从同一原件分别运行转换器。记录工具版本、哈希、退出码、警告和原件解码器来源。共享同一解码实现的转换器只能提供部分独立证据。
3. 若备选件保留目标定义，可在全新试件中试验定点恢复。先核对版本、编码、单位、外部依赖、所有者及句柄碰撞。保留原件、两种派生件和补入范围。版本、材料或引用关系不能对齐时转人工复核。
4. 重新读取试件和原件，逐项检查目标成员、顺序、几何及引用变换，并检查块外内容。重新运行模型空间与型值测试。记录仍需复看的数据，区分原始拟合点与转换器派生控制点。
5. 隔离研究可使用只读输入和单独的研究输出。任何局部检查通过或研究结果均不得开启正式放样。只有独立的工程审查流程可以决定后续生产用途。

公开版本只保存工具、合成测试与不含设计内容的汇总结果。原始日志、文件指纹、块名、句柄、图形与尺寸数据存放在案例的私有目录。此 Skill 可独立调用，尚未接入在线服务路由。
