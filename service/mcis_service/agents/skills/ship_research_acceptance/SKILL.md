# 船舶研究模型的独立验收

输入为本地只读资料目录、被测 Git 提交、研究用途授权、已知坐标与单位、允许使用的离线 CAD 内核。指定一个新的本地输出目录。开始前分别记录研究授权、工程交付授权与事故分析授权，逐项注明来源。复验时以冻结源码为准，项目资料保持在授权设备上。

1. **识别原件及独立性。** 给每个输入计算 SHA-256，记录版本、图号、工程定义、引用关系与来源族。同一文件的多个副本只算一个来源。计算模型、稳性表和设计网格若同源，标明相关性。保留同名异版，按目标量分开比较总长、垂线间长、宽、深和站距。
2. **建立可逆坐标。** 从图内站号、基线、中心线和视图约定建立站表及变换。记录原点、三轴与手性、表格数值的单位、图面比例和几何单位。用独立控制点正反算，保存误差。任一坐标解释有多解时，分别计算候选并限定用途。
3. **评估转换。** 分别核查文本与尺寸、原图句柄、块定义/引用、圆弧凸度、重复顶点、样条及视图边界。用第二条读取路径比较实际几何。记录数值限界的单位；同一参数处的距离不能直接充当双向最近距离。
4. **逐格研究采用。** 台账至少包含原始值、格定位、候选列表与来源族、推导方法、候选偏差、研究采用值、置信等级、不确定性、正式采用值。保存原始空白。先尝试原曲线与水线/纵剖面求交，再比较电子表、图纸明数、网格截面；遇多交点时核对半宽、上缘、下缘的语义。交点不唯一或低于有效域时保留未知。研究采用可依项目授权独立作出。
5. **建立实际链路。** 让后一步消费前一步实际写出的数据。在提取层的 SI 数据与横剖面接口之间组织逐站单元、显式审核及证据，防止二次缩放。按材料支持范围决定可连接的面格。用一处数值修改、一个缺测点、一处重复记录、一份待审输入检验传播及拒绝行为。外来图中的文字不能授予工程权限。
6. **生成与验收。** 线框、船体曲面、结构和上建分组保存。标明甲板封闭、对称、端部处理及估计部分。用独立读取器读回网格、CAD 和证据清单，核查单位、原点、面向、顶点、边长、面积和剖面残差。分别比较型线、剖面面积和同工况静水力；同源校核与留出验证应单独报告。正浮、零纵倾、密度或坐标定义不匹配时停止该指标的对标。
7. **交付与复做。** 输出模型及用途、证据清单、原值/研究值/正式值台账、分区置信等级、未覆盖项、误差与敏感性、程序/数据摘要及复现命令。模型只达到已实测的用途层级。将通用程序、合成夹具和允许披露的技术结论送入 QA 分支；本地台账、实船模型、来源指纹与日志留在私有目录。

## 离线校准

本仓库的 `tests_acceptance/SHIP-RESEARCH/v1_chain/run_chain.py` 可从零生成虚构 DXF，经真实研究模块输出并读回 GLB。先按同目录 README 固定源码与环境。新图纸接入时替换经审核的图层/表格/坐标映射，重新运行独立对照。通用过程不依赖特定语言模型；兼容性以相同输入和脚本的实际复跑为依据。
