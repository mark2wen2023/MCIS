## Method and scope
Nomoto/Taguchi1957 original abstract https://www.jstage.jst.go.jp/article/jjasnaoe1952/1957/101/1957_101_57/_article/-char/en explains first-order steering indices. ITTC2024 revision05 https://www.ittc.info/media/11868/75-02-06-03.pdf sections3.5-3.7 and4 address numerical checks, documented state histories, parameter/model validation. These are methodological references, NOT certification. Existing equation: dr/dt=(K*(u/u_ref)*delta-r)/T, dpsi/dt=r; psi/r/delta in degrees, r degrees/s, K1/s,Tseconds,u knots, x/y metres. RK4 motion with stepwise rudder update is not universally fourth-order accurate.

Both trajectories are hypothetical, neither measured baseline. Initial t=0,x=y=0,ROT=0,actual rudder=0. Scenario baseline has zero command; response has one Turn at t=0, headingChange=0 and signed fixed rudder, rate-limited by explicit input. Fixed speed, no drift/wind/current/wave/shallow-water/bank/interaction modelling. No safety/collision/avoidance/legal/causal verdict. Real-ship calibration and physical uncertainty NOT assessed. User must enter every active parameter and provenance/uncertainty notes; unknowns must not silently default.

ManeuverParams unused constructor fields are compatibility placeholders, not real ship attributes: speed/stop/astern time constants=1, minSpeed=0,loa=1,beam=1,displacement=1 and explicit AnchorParams(0,0,0,1,1) for let-go delay/deceleration/yaw/effective speed/full-yaw speed; anchor/size/speed-change branches disabled. Adapter tests must show varying these inactive values has no effect. Never call ManeuverParams.Default.
