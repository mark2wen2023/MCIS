# Public excerpt layout (bounded YANGZE source)

New reports may normalize the display of the existing hash-pinned public text.
Raw quote, source bytes, SHA256, physical line range and original page range remain
unchanged. A standalone decimal line is omitted only when the full pinned text
shows it immediately before a form feed and its value equals that original body
page (PDF index minus the two front-matter pages). Other numbers, footnotes and
uncertain candidates remain. Display generation states that proven page footers
are omitted; omission never changes citation coordinates.

A retained line beginning with a Chinese figure number and colon is prefixed by
an explicit editorial note: original caption, image not included, consult original.
No image is invented, loaded or claimed to be reproduced. Original quotation
attribution, needsReview, incomplete coverage and no new responsibility finding
remain. These transformations apply to new report generation, not old report or
review-history migrations. Investigator wording is never reinterpreted as source.

PDF section headings and any missing-data notice stay with the beginning of their
content. Content may continue across pages; entire long sections need not fit on
one page. This changes pagination, not stored report text. DOCX uses its existing
heading behavior. PDF text/geometry tests are distinct from developer visual review
and neither constitutes independent browser, production or factual acceptance.
