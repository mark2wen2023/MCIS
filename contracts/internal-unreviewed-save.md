# Internal unreviewed run persistence

Internal Python service only, no public endpoint/UI, approval or timeline mutation.
Save accepts strict registered IDs/mapping/declarations and a canonical operation
UUID. Caller output, returned preflight envelopes or historical receipts are not
accepted. Fixed service, adapter and core JSON protocol versions are generated by
the service. Actual core binary version is explicitly NOT attested; no executable
path, credentials or invented binary provenance is persisted.

Initial short reserved SQLite transaction checks full original-content policy,
timeline Write, actual registered bytes/review and local case/source/parent
incarnations. Core runs outside transactions on captured original bytes. Final
reserved transaction repeats checks, compares the complete snapshot, and writes
full strict historical declaration plus local index together. Return follows commit.

Local index uniqueness: globally unique run UUID; (case,localCase,operationId);
(case,auditSeq). Canonical request/operator/role digest is recomputed from full
saved declaration and audit metadata, never merely trusted from index. Replays
validate whole chain/index/marker/current source snapshot and current full policy.
Same operation but different request/identity conflicts; stale source/epoch/review
or revoked permission refuses result. Current-generation marker without index is
an integrity error, not a new operation or automatic index repair.

Concurrent same-operation workers may both compute; final writer checks the winner
and returns its existing run, adding no second record. Competing requests for one
operation conflict. Unknown delivery after commit may be reconciled using the same
operation ID only while scope/permissions/current versions remain valid. This does
not promise exactly-once computation or delivery.

New saves require optional-v1 historical operationId and processing fields; old
valid v1 history without these remains supported. Export checks complete current
local marker/index bijection and schema/hash chain before permitting operational
table. Imported declarations remain history, never rebuild local indexes or replay
permissions; new local case incarnation isolates the same historical operation ID.

Actual escaped cumulative audit bytes are capped before commit, reserving64KiB
within existing16MiB member budget; failure rolls back audit/index. Headroom cannot
guarantee unlimited later audits/export growth. Existing package budget/default
policy/entry restrictions remain; full production archival scalability is not claimed.
