# W20.2 笔录抽取与人工审核界面（仅既有API）

基线 b64812b。位置：W5 询问笔录页，专属面板。只处理 people_ops / statement_extraction / interviewStatements 草稿；不修改已有比对逻辑、W20后端或合同字段，不接通其他五角色。

## 专业依据与转化（2026-11-12查核）

- [IMO MSC.255(84)](https://wwwcdn.imo.org/localresources/en/KnowledgeCentre/IndexofIMOResolutions/MSCResolutions/MSC.255%2884%29.pdf)，§22.2、23：笔录等证据需妥善控制访问与披露。本片复用后端权限/脱敏，角色变化立即清空旧内容，不把隐藏按钮当授权。
- [NIST AI 600-1](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf)，§2.2、MS-2.5-003、MS-2.5-001：生成内容可能错误，出处和模型能力需要核查。本片分离配置、返回草稿和人工确认，逐条并列原文引用与候选解读；不把引文一致说成事实正确，也不把假服务测试说成真实推理。
- [WCAG 2.2 4.1.3解释](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)：等待/成功/错误使用可读状态语义；[3.3.4解释](https://www.w3.org/WAI/WCAG22/Understanding/error-prevention-legal-financial-data.html)启发明确核对与确认步骤。这是本片设计依据，不是宣称全站WCAG合规或法律认证。

## 流程及边界

1. 绑定当前 ?case、身份与所选笔录；身份/案件/笔录切换不显示旧响应或旧审核勾选。六角色状态来自 GET /agents；configured 只表示配置可用，不代表连接或推理质量验证。未配置/配置错误/加载失败不能启动。
2. 只有明确点击才POST当前record提取；不自动推理、不设置密钥、不改变模型配置。调查组或AgentService可请求；后端权限仍是最终判断。
3. 读取当前案件drafts，拒绝跨案响应；仅列当前笔录本片草稿。显示ID、状态、模型、时间UTC、sourceDigest/promptDigest与每条问次/问答字段/逐字引用、摘要及claim。现有W5全文紧邻保留，不按脱敏后的偏移伪造高亮。
4. PendingReview仅调查员可确认或驳回。确认须逐条勾选已核对出处与含义，再点击明确写回按钮；驳回要求理由。本片不提供Modified编辑器，其他客户端产生的Modified历史仅展示。修改后的语义是否获原文支持仍由人工核对，不能只看引用存在。
5. 成功以服务响应匹配case/record/draft/decision为准，之后重读队列；确认后刷新W5笔录与计数。重复点击由同步锁防止。后端拒绝、来源变化或已有审核不伪装成功。
6. 页面会话内跨挂载写锁保留，旧请求可以完成但不能污染新上下文。网络/不明服务端错误或不匹配的成功响应标“结果未确认”，不自动重发；读取队列后需操作者明确核查审计/草稿再解锁。服务端没有幂等键；整页重载后的重复操作风险仍需核查，不宣称全局恰好一次。
7. 未授权角色不请求/呈现草稿；AgentService不能审核。单独UI控制不代替后端权限，现有role-header仍非生产认证。

## 验证与限制

实测至少覆盖：未配置/配置错误/模型失败、真实本机HTTP假模型→草稿→确认/驳回、来源变化、重复审核、后台403、未知结果恢复、跨案/身份/笔录与迟到响应、防双击、长文本HTML转义、键盘/移动布局。真实模型不在环境时只用合成材料与明确命名假模型，不用真实用户笔录或对外发送。本片没有OCR/ASR/图像/视频输入、任意草稿编辑或生产部署。
