## 构建与本地查看
需要已有兼容 Node、React、react-dom、esbuild 依赖（web/package-lock.json）。开发方复用现有 node_modules；未验证全新安装。不要启动 run_dev、Vite 主应用或 Python 服务；后端启动及归档暂停不变。

从仓库根目录：
```sh
node web/preview/report/build.cjs /tmp/mcis-report-preview-new
```
目标须为尚不存在的绝对目录；换成自己控制的新临时目录。脚本输出 draft.html、modified.html、missing.html 和依赖清单。用正常浏览器“打开文件”分别查看三个 HTML，不需要 HTTP 服务，不发布站点。若环境阻止打开，停止，不关闭沙箱或改变安全设置。关闭页面即结束，无服务需停止。

只允许手造数据，不打开仓库案例或加入真实资料；克隆仓库不等于净化数据。

## 同事可执行的视觉验收
- 中文草稿长文本在宽屏与窄窗是否可读、重叠或溢出；报告标题、状态和缺引用提示是否明确。
- 双语修改的中英文、需复核标识、继承引用警示和原文折叠区是否可辨认。原生 details 可展开，不产生请求。
- 英文缺失状态能否清楚区分没有数据与已确认事实。
- 所有业务按钮/选择框处于不可操作 fieldset 内；引用没有 href。组件原有 LIVE 标签仍显示，但顶部明确说明它不是服务连接。
- 浏览器网络面板应无 HTTP/业务请求；页面无脚本及外部资源，CSP 禁止连接、脚本、表单。记录浏览器版本、窗口大小、截图与具体问题，不把构建记录当视觉通过。

不可验收：保存、刷新、切案、身份、读写权限、并发、中断渲染、报告生成、导出 PDF/DOCX、真实引用跳转或后端合同。静态页不是这些能力的替身证明，也不是生产版本。
