# 报告解析服务智能体说明

六个角色分工，不要让一个模型一次做完全部抽取。输入是已经清洗过的报告文本（建议 PyMuPDF）加上需要读图的页面渲染。输出必须是 JSON，且每个字段带 `source: {page, quote, pdfPage?, figure?, note?}`。提取不到写 `null`，禁止编造，禁止在多源冲突时静默取舍。

建议调用顺序：

1. 并行：`01_vessel`、`02_timeline`、`03_environment`、`04_personnel`、`05_causes_ecfc`
2. 最后：`06_aggregate` 合并、表4校验、冲突列表、缺口列表

所有智能体共用的约束：

- 时间同时给北京时间和 UTC，并写明报告用的是哪一种时钟。
- 页码优先用正文“第 x 页”，另存 PDF 页。
- 坐标保留原文度分秒/小数分，同时给出十进制度。
- 图表中的数字必须能在对应渲染图上对上，才能入库。
- 输出语言：中文叙述，枚举值按 schema。
