# W19 离线知识候选审阅页（研究增量）

目的：将来源闸门的候选呈现为人可以逐条阅读、对照原文的静态 HTML，不增加生产接口或改变既有 W19 发布流程。

运行：`python -m unittest -v`。调用 `render_preview.render(raw_bytes, sources, known=())` 获取完整 HTML 字符串。所有输入先经过同目录 gate.py 校验，不能直接传入伪造的“已验证”预览对象。gate.py 是 PR #50 的既有闸门快照，未修改原文件。

显示标题、主张、原文摘录、来源编号/版本、字符区间、材料位置、哈希、候选指纹、完全重复数量。模型内容全部转义，只作文本，来源位置不生成外部链接。无脚本、外部资源、表单、审核或发布按钮；CSP 禁止外部资源与表单提交。公开/虚构标志沿用授权来源快照，不采信候选自称。

边界：只读离线研究页，不是正式管理面板。未接真实模型、数据库、认证、API 或人工审批工作流，不证明事实成立或来源真实。不写候选、不发布、不修改状态；HTML 文档中无可提交数据的动作。没有浏览器截图或浏览器级 CSP 验证，当前只验证生成结构与转义。完整源码、哈希及本地测试记录保存在本目录。

## 合同提案

本新增函数是研究目录局部接口，未修改已冻结合同。日后接入生产 UI 前需单独在 REQUESTS.md 登记、完成认证和案件范围校验，并独立验收；不可将此页当作正式审核结果。

## 2026-11-13 逐条引用性质标记
每一条引用现在显示来自 gate 校验后来源快照的 Public（公开材料）或 Synthetic（虚构材料）标记，并保留“未核实”。混合来源不再只能从候选级提示猜测；候选自报 sourceType 仍被 gate 拒绝。公开标签不认证内容、使用权或事实，来源登记本身也尚非生产认证。没有增加来源访问、数据发送、审核或发布动作。
旧实现摘要保留于 SHA256SUMS.v1，新摘要见 SHA256SUMS / SOURCE-LABELS-SHA256SUMS。原 9 项加新增 6 项本地 unittest 通过，独立验收另列。仍无浏览器视觉验收或真实模型。
