# W19 自动沉淀候选来源闸门（隔离实验）

已有 W19：人工知识卡录入、首席人工审核发布/撤回、字面检索、模板整理预览、独立历史归档。自动抽取后怎样防止伪造引用、跨材料引用、失效版本进入待审内容，尚未有接入流程。本实验补其中一段可执行边界，不替代原有审核。

## 运行

```bash
cd experiments/knowledge-candidate-gate
python -m unittest -v
```

仅 Python 标准库，无安装、网络、模型调用、数据库修改。`Source` 由服务端未来从已授权材料构建，抽取器只返回候选 JSON；`gate(raw_bytes, sources, known_fingerprints)` 返回待审预览或者整体拒绝。例子全部是虚构材料。

## 已实现

- 按调用者固定的 sourceId、版本和原始提取文本哈希绑定材料，不让模型自行增加来源。
- 原文精确区间核验，拒绝伪造摘录、失效版本、范围错误和未知来源。
- 公开/合成标签来自材料快照；混合来源不得隐藏合成标记。
- 同批及已知指纹的完全重复识别。不声称语义去重。
- 所有主张保持 Unverified，始终人审、禁止发布；恶意指令仅当字符串保存。
- 批次严格字段/编码/数量/大小校验，任何无效条目整批失败，无部分持久化。

## 未实现、不可声称

这不是“AI自动读报告已做好”。没有真正LLM/多模态解析、生产UI/API、持久化候选队列、真实认证、权利审查、语义去重、审查工作流接入或自动训练。文字哈希不证明报告真实性；正确引用也不证明主张被支持。发布仍须通过未来与现有 W19 人工审核的显式接入，不能直写 Published。

27 个自测方法通过（test.log）。仅隔离标准库测试，不是独立验收、CI、生产服务回归或浏览器测试。CONTRACT.md 为新接口的先行提案，未修改既有冻结接口或共享入口。

## 独立审查返工

独立审查通过原有 24 项及 Unicode/版本/指纹补测，另发现合法输入大小内的 5000 位整数可触发 Python 裸 ValueError。现已在整数转换前限制六位数字并规范解析错误，新增正负大整数、引用区间大整数及位数边界回归。修复后独立复验 27/27 通过，原始正负5000位整数探针均返回 Invalid NUMBER_BUDGET，另12项 Unicode/版本/来源权限边界/去重检查通过。仅隔离实验验收，不是生产或真实模型验收。
