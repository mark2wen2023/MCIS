# W19 candidate provenance gate (isolated proposal v1)

Scope: pure Python validation of an extractor's proposed knowledge candidates against caller-pinned, immutable text snapshots. This is a boundary before W19 human card review, not a new publication path. Existing W19 template stub, review endpoints, archive and UI remain untouched. No network, model, database, authentication or source-file parser is provided.

The host, not the model, constructs `Source` objects from explicitly selected Public/Synthetic material and supplies them to `gate`. Source text is bounded to 200,000 Unicode codepoints, each batch to 16 sources and 512 KiB UTF-8, candidate payload to 64 KiB / 32 candidates / 8 citations each. Limits are engineering budgets, not professional investigation thresholds. `source_id`, version and locator are host labels. Hash covers original extracted text UTF-8, not PDF bytes or truthfulness. Extraction/ OCR needs separate provenance in production.

Untrusted input: strict JSON exact root `{candidates:[...]}`; each candidate has `kind,title,claim,citations`; each citation has `sourceId,version,textSha256,start,end,quote`. Offsets are zero-based Unicode codepoints, end-exclusive, in **the exact immutable text**, not bytes, pages or normalized text. Bool is not an integer. JSON integer tokens are capped at six decimal digits (excluding minus) before conversion; larger tokens yield `Invalid("NUMBER_BUDGET")`. Actual offsets must still fit the selected source. Parser failures are normalized to `Invalid` without changing specific gate errors. A quote must match that slice exactly and have non-whitespace text. Hash/version/source must match pinned snapshot. No URL is fetched. Unknown fields, invalid encoding, duplicate keys, NaN and budgets fail the entire batch without partial output. Exact allowed kinds: Case, Challenge, Method.

Successful output is an unpersisted `CandidatePreview`, never Published. Each candidate carries all pinned source metadata, verified extract spans, `sourceTypes`, and `synthetic` if any source is Synthetic; labels are generated by the gate, never by model. `claim` remains unverified model text, not entailed by the quotes. Duplicate detection is exact canonical content fingerprint only, not semantic deduplication. It covers the current batch and supplied previously-known fingerprints. Source identity, version and quote offsets participate: changed provenance is not silently collapsed. No approvals or human identity are generated.

Integration pending: immutable source store, current authorization and rights checks, durable queue/audit, idempotent persistence, UI editing and human W19 review. Production must not treat this pure preview as a durable candidate or a fact. Model output and quoted source text are untrusted data, never instructions. Do not send private case data to a provider without task-specific permission.
